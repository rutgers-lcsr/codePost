# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any codePost component, please report it privately to **codepost@cs.rutgers.edu**.

Please do **not** open a public GitHub issue for security problems.

Include in your report:
- Which component is affected (api, ui, sdk, deploy config).
- A description of the issue and its impact.
- Steps to reproduce, or proof-of-concept code.

We will acknowledge your report within 3 business days and work with you on a coordinated disclosure timeline.

## Component-specific policies

- Backend: [codePost-api SECURITY.md](https://github.com/rutgers-lcsr/codePost-api/blob/main/SECURITY.md)
- Frontend: [codePost-ui SECURITY.md](https://github.com/rutgers-lcsr/codePost-ui/blob/main/SECURITY.md)
- Python SDK: [codepost-python SECURITY.md](https://github.com/rutgers-lcsr/codepost-python/blob/main/SECURITY.md)

All reports go to the same address regardless of component.
